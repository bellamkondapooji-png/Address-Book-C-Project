# Address Book Management System in C

A console-based Address Book application developed using C programming.

## 📌 Project Overview
This project is designed to manage contact information efficienntly. It allows users to create, search, edit, delete, list and save contacts.

## ✨ Features
- Create a new contact
- Search for contacts
- Edit existing contacts
- Delete contacts
- Display all contacts
- Save contact information to s CSV file
- Menu-driven console interface

## 🛠️ Technology Used
- C programming
- Structures
- Functions
- File Handling
- Arrays
- Pointers
- CSV file Handling
